## التشغيل

```bash
python3 serve.py --port 8080
# أو
./start.sh
```

يُطبع عند التشغيل عنوان الجهاز على الشبكة، افتحه من متصفح البلايستيشن:

```
http://<عنوان-جهازك>:8080/
```

## الخطوات على الكونسول

1. تأكّد أن البلايستيشن والجهاز على الشبكة نفسها.
2. افتح العنوان أعلاه من متصفح البلايستيشن.
3. اختر إصدار النظام.
4. تُثبَّت الحزمة المحلية تلقائيًا — بعدها أغلق المتصفح وأعد فتحه للعمل دون إنترنت.

## معاينة الواجهة على الجهاز

أضف `?preview=1` إلى أي صفحة لعرض القائمة دون تشغيل الاستغلال:

```
http://localhost:8080/900v3/index.html?preview=1
```
