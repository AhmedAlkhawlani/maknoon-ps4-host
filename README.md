## الخطوات على الكونسول

1. تأكّد أن البلايستيشن والجهاز على الشبكة نفسها.
2. افتح العنوان من متصفح البلايستيشن.
3. اختر إصدار النظام.
4. اتركه حتى ينتهي **تثبيت الحزمة المحلية**، ثم أغلق المتصفح وأعد فتحه.
5. بعد ذلك يعمل بلا إنترنت: افتح المتصفح واختر البايلود.

## إضافة بايلود جديد

1. ضع ملف `.bin` في مجلد الإصدار المناسب (مثل `900v3/`).
2. أضف زرًا في `index.html` داخل `<div id="menu">`:

```html
<button class="btn" onmouseover="msgs.innerHTML='وصف البايلود'"
        onmouseout="msgs.innerHTML='جاهز · اختر بايلودًا'"
        onclick="load_myPayload()"> اسم البايلود </button>
```

3. أضف الدالة في آخر الصفحة:

```js
function load_myPayload(){
  LoadedMSG = "تم تحميل البايلود ...";
  PLfile = "my-payload.bin";
  load_poc();
}
```

4. أضف اسم الملف إلى `cache.manifest` في المجلد نفسه — **وإلا لن يعمل أوفلاين**.

## ملاحظات تقنية

- **المنفذ 8080 متعمّد:** `9020` محجوز لـ Bin Loader و`3232` لاستغلال 9.00.
- **`.manifest`** يجب أن يُقدَّم `text/cache-manifest`. سيرفر `serve.py` يضبط ذلك، وGitHub Pages يفعلها تلقائيًا — بدونها لا يعمل الكاش المحلي.
- **`.nojekyll`** يمنع معالجة Jekyll على Pages ويسرّع النشر.
- **التصميم** مكتوب بأساليب متوافقة مع متصفح PS4 القديم: بلا CSS Grid، بلا `custom properties`، بلا `clamp()`.
- **بايلودات الاستعادة** (`restore/*/payload.bin`) هي shellcode خام. عُدّل النص والرابط داخلها بجراحة: الاسم في مكانه، والرابط الأطول أُلحق بنهاية الملف مع إعادة توجيه تعليمة `lea` الواحدة.
